# 📦 Web Inventory

Aplikasi pengelolaan inventaris barang yang dikembangkan untuk pembelajaran dasar pemograman website semester 2.

## 🔧 Tech Stack

- HTML
- CSS
- JavaScript
- PHP Native
- MySQL

## ✨ Fitur

- fitur CRUD
- Login Multi User
- Riwayat transaksi

## 🚀 Cara Menjalankan

1. Clone repo ini
2. Jalankan di XAMPP / Laragon
3. Import database ke phpMyAdmin
